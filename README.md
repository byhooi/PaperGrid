# PaperGrid

纯前端稿纸生成器，支持中文作文纸、英语四线三格和课业横线纸。没有后端，没有数据上传，也不依赖在线 CDN。

## 运行

推荐在项目根目录启动静态服务器：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000`。无需安装 npm 依赖或构建。也可以直接打开 `index.html`；部分浏览器对本地文件的字体和持久存储有限制，遇到问题请使用静态服务器。

支持当前版本的 Chrome、Edge、Firefox 和 Safari。移动端通过“调整设置 / 纸张预览”切换工作区。初次导出 PDF 时才加载本地 PDF 引擎。

## 使用与输出

- 支持 A3、A4、A5、ISO B4（250 × 353 mm）、ISO B5（176 × 250 mm），以及横竖版、单双栏和 1–20 页。
- 作文纸“自动适配页面”使用能容纳的最大正方格，保持行列数与槽高规则，剩余空间在各栏内居中留白；不再分别拉伸格宽、格高。关闭后按栏宽确定正方格尺寸，放不下会提示并禁止导出，不会静默缩小或裁切。
- 400 字预设保留 20 列 × 20 行，使用格高 30% 的比例行间槽，在书写间距与竖版留白之间折中，不强制铺满页面。更新后需重新点击该预设才会应用新参数；已保存的自定义配置不会被自动改写。
- 固定槽高按毫米计算；比例槽高随格高变化。横版单栏 300 / 400 字配置可主动点击“应用横版推荐”，分别调整为 25 列 × 12 行、25 列 × 16 行并开启正方格适配，总字数及其他设置不变。仅切换方向不修改行列数或分栏。
- 英语纸、横线纸勾选“按行数铺满”时保持行数，自动计算实际尺寸；英语纸保留“组高 : 间距”的比例，上方毫米数仅作比例基准。取消勾选则保持指定书写尺寸，超高时提示可容纳组数／行数，不自动减行。实际打印尺寸在设置区与预览标签中显示。
- PDF 和打印包含全部页面；SVG、PNG 只导出当前预览页，可先翻页再导出。信息栏和题目行仅在第一页显示，字数跨栏、跨页连续计算。
- 预览、SVG、PNG、PDF 共用以毫米为单位的绘图数据。PDF 保留矢量线条与文字，并嵌入中文标签字体及选定底色。
- PNG 提供 150 / 300 DPI 对应的像素尺寸，例如 A4 300 DPI 为 2480 × 3508 像素。浏览器 PNG 编码的分辨率元数据可能仍为 96 DPI；需要准确物理尺寸时请打印 PDF。
- 打印选择“实际大小 / 100%”，关闭“适合页面”。PDF 阅读器若未自动调起打印，请手动打印。实际可打印边距取决于打印机；全页底色也可能受打印机无边距能力限制。

## 配置与模板

有效配置在修改后自动保存到当前浏览器，可恢复默认，或保存最多 20 个具名模板。切换纸张类型保留通用设置和各类型参数；点击预设会明确替换全部配置。

配置仅保存在当前站点的 `localStorage`，不跨浏览器同步。隐私模式、禁用存储或清理站点数据会影响保存，重要模板请导出 JSON。导入上限为 64 KB；支持原项目无版本号的 JSON，旧版行槽按比例恢复。

```json
{
  "version": 1,
  "config": { "paperType": "composition", "pageCount": 2 }
}
```

缺省字段使用默认值；未知字段、错误类型、非法颜色、超界参数或无法排版的组合均被拒绝。导入失败不修改当前配置。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `config.js` | 默认配置、预设、字段校验与 JSON 版本兼容 |
| `layout.js` | 无 DOM 依赖的毫米布局计算和边界检查 |
| `render.js` | 通用绘图数据与 SVG 序列化 |
| `exports.js` | PDF / SVG / PNG 导出、字体与资源加载 |
| `app.js` | 表单、预览调度、缩放、翻页、持久保存 |
| `assets/` | 固定版本的离线 PDF 引擎和字体资源 |

脚本按顺序使用 `defer` 加载，通过 `globalThis.PaperGrid` 共享接口，不要求打包器。预览通过 `requestAnimationFrame` 合并更新；仅修改页数或 PNG DPI 时不重建当前页面 SVG。

## 验证

在 PowerShell 中运行基本检查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify.ps1
```

该命令检查语法、离线资源、空白错误，并运行无需第三方依赖的布局回归（也可单独执行 `node scripts/test_layout.js`），不代替浏览器验证。修改排版或导出时，按以下清单验证：

- 三种纸张 × 横竖版 × 单双栏；A3/A4/A5/B4/B5 纸张尺寸；作文格宽高相等且栏内居中，不对称边距下双栏折线位置不变。
- 横版推荐仅在单栏 300 / 400 字作文配置中显示，点击后总字数、页数、边距与颜色保持不变；仅切换方向不改行列数。
- 英语／横线纸两种尺寸模式的说明与实际毫米尺寸一致；关闭铺满后超高提示正确，输入框仍可编辑，按建议减少行／组数后恢复。
- 固定槽高 4 mm、0 mm，比例槽高 0% / 50%，最小边距配页码，首尾页边界。
- 关闭自动铺满并输入超高内容，应提示且禁止导出；修正参数后恢复。
- 导入非法颜色、负数、超大页数、未知字段、错误版本及损坏 JSON；原配置保持不变。
- 两页以上 PDF 的中文页眉、背景色、页码与跨页字数；SVG/PNG 对应当前页。
- 300 DPI A4 PNG 的像素尺寸；PDF 纸张物理尺寸；屏幕与 PDF 的坐标、字号和线型。
- 390 px 手机宽度下设置/预览切换，键盘操作颜色按钮，窗口缩放后整页适应。
- 刷新恢复配置、自定义模板保存/删除、存储不可用、资源加载失败重试。
- 断网刷新并导出三种格式；打印窗口被拦截时有提示。

## 第三方资源

- jsPDF **4.2.1**，MIT：`assets/jspdf-4.2.1.umd.min.js`、`assets/jsPDF-LICENSE.txt`。来自 `https://cdn.jsdelivr.net/npm/jspdf@4.2.1/`。
- Noto Sans SC，SIL OFL 1.1：来自 Google Fonts 的 `ofl/notosanssc/NotoSansSC[wght].ttf`，许可证见 `assets/NotoSansSC-OFL.txt`。项目将其裁剪为 ASCII 和固定中文标签、固定字重 400，并重命名为 **PaperGridSans**；没有使用系统商业字体。
- `assets/PaperGridSans.ttf` 用于浏览器预览，`assets/papergrid-font.js` 是同一字体的 Base64 资源，用于导出。两者必须一起更新。

字体更新时安装 Python `fonttools`（仅开发用途），下载上游字体，再运行：

```sh
python scripts/subset_font.py path/to/NotoSansSC.ttf
```

如果新增可打印文字，请同步扩充脚本中的字形集合。仅修改界面文案不需要重新生成字体。
